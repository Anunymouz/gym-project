# 09 — Name Check: "Orbyt"

*Checked 2026-11-13 using web searches. The session's network blocks domain lookups (RDAP/WHOIS/DNS), so domain availability is **not** confirmed. Not legal advice; a trademark lawyer should do the final clearance.*

## Story
"Everything that moves you, in your orbit." The app draws a circle around the user (location + radius) and shows the gyms, trainers and gear inside it. The orbit moves with you, from Accra to anywhere, so the name fits expansion.

## Findings

| Ghana trademark | No online search done; Ghana's register isn't searchable this way. | Unknown: lawyer search needed |

## Decision
**Adopted (2026-11-13):** brand **Orbyt**, app store name **Orbyt Fit**.

## Verdict
**Orbyt is usable in Ghana and Africa with a fitness qualifier, but the plain word is crowded, and a registered or pending US mark in the mobile-app class blocks clean US expansion.**

If we go ahead:
- **Brand:** Orbyt
- **App store name:** "Orbyt Fit" or "Orbyt: Gyms & Trainers"
- **Domain:** prefer orbyt.fit or orbytfit.com (getorbyt.com as backup)
- **Handles:** @orbytfit everywhere for consistency
- **Trademark:** file in Ghana first, then through the Madrid Protocol / ARIPO for target markets. Classes 9 (app), 35 (online retail / marketplace), 41 (fitness training services), 42 (software for gyms).
