# 10 — Name Check: "BGYM"

*Checked 2026-11-13 using web searches. The session's network blocks domain lookups (RDAP/WHOIS/DNS), so domain availability is **not** confirmed. Not legal advice; a trademark lawyer should do the final clearance of the name and logo.*

## Verdict
**BGYM is usable for launching in Ghana and Africa**, where no one is using it. The main conflict is the Taiwanese fitness-equipment brand and its pending US trademark in Class 28. This matters most:
- **in the US**, and possibly in Asian markets they sell in;
- **if we sell BGYM-branded equipment or merchandise** (dumbbells, apparel), which sits close to their Class 28 goods.

Our core business is an app, a marketplace and fitness services (Classes 9, 35, 41, 42), which is a different category. Even so, an identical name in the same broad industry means a lawyer needs to confirm it.

## Recommendations
- **App store name:** "BGYM: Be my gym buddy" (distinct from "BGYM M718").
- **Domain candidates:** bgym.app, getbgym.com, bgymapp.com, bgym.africa, bgym.com.gh (bgym.com is likely taken).
- **Handles:** a consistent `@bgymapp` (or `@bgym.app`) on Instagram, TikTok, X and Facebook.
- **Trademark:** file "BGYM" (word + logo) in **Ghana first**, in Classes 9, 35, 41 and 42. Ask the lawyer about Class 28 / 25 before launching any BGYM-branded equipment or apparel in the store. Watch serial 97701162 before any US launch.
- **Logo:** have the lawyer clear the athlete mark too, since muscled-figure gym logos are common.
